## Pinned-issue

**arcus-provider-runtime v0.8.2 released — whole PDFs, flagged caps**

What you'll notice as a consumer:

1. PDF text comes back whole. Papers that used to stop around page 12 now include every page, and their late figures sit next to their own text.
2. Figures whose caption sits a few lines below the image (after axis labels or a legend) now carry that caption.
3. docx/xlsx/pptx/epub text over `ExtractionLimits.max_text_chars` (default 50,000) is flagged: `extractor_detail["truncated"] = true`, `truncated_reason: "max_text_chars"`, `original_chars`. Pass `ExtractionLimits(max_text_chars=None)` for no cap.
4. The `[pdf]` extra stays on pymupdf4llm 1.x; a 2.x install is flagged with a `PYMUPDF4LLM_UNSUPPORTED` warning.
5. The URL guard handles malformed requests more robustly.

Full changelog: https://github.com/jivebug/arcus/blob/main/CHANGELOG.md#082--2026-11-22

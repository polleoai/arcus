## Headline

What a source says stays text in your notes: no captured page, file or video can make your note load, link or run anything. Captured text is now escaped Markdown for every provider, an output change.

## Short post

arcus-provider-runtime v0.10.0 ships today: a security release with an output change (captured text is now escaped Markdown for every provider).

→ Text from any source (web pages, PDFs, Office files, e-books, plain text, YouTube captions, OCR) can no longer become a live image, link, embed, wikilink, code block, Dataview query or field, or Templater command in the note.
→ Markdown files keep their structure, sanitised: raw HTML shows as text, links and embeds go only to http(s).
→ A broken or hostile page with unclosed tags converts in milliseconds instead of minutes.
→ Web pages keep their lists, quotes and links around buttons and search boxes, and no longer open with a site menu that isn't marked up as one.

## Pinned-issue

**arcus-provider-runtime v0.10.0 released — captured text stays text (output change)**

What you'll notice as a consumer:

1. Text a source shows as `<img …>`, `![x](url)`, `[[note]]`, `` ```dataviewjs ``, `$= …`, `key:: value` or `<% … %>` comes out as that text, not as markup Obsidian renders, fetches or runs. It reads the same; the raw note holds escapes such as `\[`, `` \` `` and `:\:`.
2. Links and images keep only `http`/`https` targets; any other scheme keeps its text but is no longer a link.
3. `.md` sources keep their Markdown, sanitised: raw HTML is shown as text, code blocks keep only plain language names, and the file's own frontmatter is shown as a `yaml` block.
4. **Output change, library callers:** `ExtractionResult.text` and segment text are now escaped Markdown for every provider (hence 0.10.0, not a patch). Use them as Markdown, not as raw text.
5. Pages with unclosed tags convert in linear time; well-formed, browser-rendered pages convert as before.

Full changelog: https://github.com/polleoai/arcus/blob/main/CHANGELOG.md#0100--2026-11-25

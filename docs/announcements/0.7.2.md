## Pinned-issue

**arcus-provider-runtime v0.7.2 released — guarded routing is independent of proxy environment**

What you'll notice as a consumer:

1. If you use `set_url_guard` / `using_url_guard`, upgrade: environment and system proxy settings no longer influence where a guarded fetch connects.
2. While a guarded YouTube fetch runs, proxy variables are hidden process-wide and restored afterwards; other threads briefly connect without the environment's proxy.
3. Without a guard, nothing changes.

Full changelog: https://github.com/jivebug/arcus/blob/main/CHANGELOG.md#072--2026-11-22

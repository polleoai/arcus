## Pinned-issue

**arcus-provider-runtime v0.7.2 released — guarded routing is independent of proxy settings**

What you'll notice as a consumer:

1. If you use `set_url_guard` / `using_url_guard`, upgrade: proxy settings from the environment or the operating system no longer influence where a guarded fetch connects.
2. It applies only to the guarded call's own thread — nothing process-wide changes, and unguarded code keeps its normal proxy behaviour.
3. Without a guard, nothing changes.

Full changelog: https://github.com/jivebug/arcus/blob/main/CHANGELOG.md#072--2026-11-22
